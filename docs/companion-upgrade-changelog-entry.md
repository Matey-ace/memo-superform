## 陪伴升级首版

本轮加入三项能力：**长期记忆**、**多角色批量安装**、**真实词汇学习进度与角色结算奖励**。

### 长期记忆

- 记忆分三类：用户主动偏好（`preference_name` / `preference_goal` /
  `preference_encouragement`）、角色会话摘要（`role_summary`）、已确认学习事实
  （`study_session`）。
- 只有**已确认结算**的事实会进入记忆。页面点击、AI 回复、`finish` 事件都不产生记忆。
- 检索有硬上限：最多 5 条、1200 字符、单条摘要 400 字符。上下文不会挤掉学习内容。
- **出站默认关闭**：未经你在设置里显式开启，记忆不会进入任何 AI 请求。
- 删除是即时生效的：删除后该条不再出现在后续提示中，并记录删除日志。
- 保留期默认 90 天，过期会话条目自动清理，角色摘要保留（不丢长期印象）。
- AI 注入只改写 `system` 消息，绝不改写你输入的内容或历史对话。

### 多角色批量安装

- 一个 ZIP 可含多个角色，一次检查、逐角色提交。
- 检查阶段先算出"会装成什么"，此时不落地任何文件；确认时**重新核对**
  ZIP 的 sha256 与角色集合，防止两次点击之间包被换掉。
- 单个角色失败只回滚该角色，其余照常装完（作业状态显示为 `partial_failed`）。
- 升级已安装角色时沿用同一 `role_id`，因此**长期记忆与结算历史不会丢失**；
  你在设置里手改过的人设不会被包覆盖（除非包显式声明要替换）。
- 拒绝越界路径、绝对路径、盘符与任意下载 URL；只接受受控导入目录内的来源。
- 作业写入原子日志，启动时恢复中断的作业，已提交的角色不会回滚。

### 学习进度与结算

- 进度分**本轮**与**今日**两个数字，互不冒充。今日目标尚未同步时显示"待确认"，
  不会伪造分母或百分比。
- 完成判定只看**最后可信证据**：完整官方计划 + 已核验身份 + 进入本轮后真正发生的
  `false→true` 转变。进入本轮前就已完成的词不计入本轮新增。
- 有效学习时间按多个窗口的**区间并集**统计，不累加客户端秒数（否则双窗会翻倍）；
  暂停、心跳中断、长闲置都不计时。
- 一次完成只发一次奖励：结算、纪念卡、首次完成徽章、记忆入队各有唯一约束，
  重复提交/刷新/双窗返回同一份结算。
- 结算演出**本地优先**：祝贺文字立即显示，不等待网络。AI 每个结算最多请求一次，
  失败静默降级。重看历史结算不会重放语音与动作。
- 若结算对象已变化（换了会话或角色），会提示"这一轮记录已更新"并停止对应语音。

### 内部改进

- 新增角色包安装原语 `tts.install_role_resources`，支持创建与升级两种模式，
  失败时清单、人设与资源全部复原，且只回收本次创建的目录。
- 新增 Live2D 目录批量下载，串行化以避免并发下载互相打断，支持取消与部分失败识别。
- 数据库新增 14 张 `companion_*` 表与 7 个部分唯一索引；既有表结构与数据未变。
- 新增三道删除屏障（学习数据 / 账号 / 单角色），代次推进即失效，旧数据不参与判断。

### 已知限制

- 网页内嵌学习与开放 API 账号之间的映射**尚未取得核验证据**，因此真实环境中
  网页学习暂不产生结算。官方进度仍可正常显示。
- 今日目标的完整性判定需要真实上游响应确认字段形状；在此之前一律安全降级为不结算。
