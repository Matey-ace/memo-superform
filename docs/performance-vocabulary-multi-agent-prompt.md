### 官方 API 已核实

唯一权威参考：[官方入口](https://open.maimemo.com/)；[官方 OpenAPI YAML](https://open.maimemo.com/api_bundle.yaml)。执行时重新获取，公测契约可能变化。

1. `POST https://open.maimemo.com/open/api/v1/memo/vocabulary/query`
   - 可按 `spellings` 或 `ids` 批量查询，两种查询条件互斥；每批最多1000。
   - 请求示例：`{"spellings":["resilient","subtle"]}`。
   - 返回 `voc` 数组，元素包含 `id` 与 `spelling`；不能假设返回顺序和输入顺序一致或全部命中。
2. `POST https://open.maimemo.com/open/api/v1/memo/study/add_words`
   - 请求：`{"words":[{"id":"实际查询到的ID"}],"advance":false}`，最多1000词。
   - `advance` 必填；默认 false，不擅自改变用户复习时间。
   - 返回 `added_count`，重复词与单词上限不足会影响数量。没有逐词成功结果，不得编造。
   - 官方明确：公测不保证可用性、可能随时调整，需要在 App 中开启自动同步。
3. 云词本也支持创建和更新，但不是“加入学习列表”的替代。首版直接使用 add_words；可选保存云词本属于后续功能，不默认发布原文或例句。
4. 官方总频控：10秒20次、60秒40次，墨墨背单词5小时2000次；执行时复核。项目已有共享限流，不要为新功能另造互不相干的限流器。
5. [server.py](<../server.py>) 861-904 的路由白名单当前没有 vocabulary/query 或 study/add_words，需要按确切路径增补，而非开放任意代理。
6. [maimemo_auth.py](<../maimemo_auth.py>) 已声明 open.memo.study/open.memo.content，但不能仅凭 scope 字符串证明真实账号可调用新增公测接口。真实权限与自动同步要验收。
7. [server.py](<../server.py>) 724-734 会给通用 AI 请求注入陪伴记忆。结构化文章选词应隔离不相关角色记忆，不能因人设改变 JSON 格式或选词依据；同时不得破坏原陪伴功能。

1. 目标是在现有功能、视觉、音质、学习语义与数据完整性不降低的前提下，减少无效计算、重复 IO、常驻资源、启动开销与发布资源冗余；新增文章自动精选词汇并通过官方 API 加入学习列表。
2. **按无限 Token 调用预算组织任务**：不设人为 Token、研究轮次或必要子智能体调用次数上限，不因节省 Token 省略代码调查、测试、复核或修复。实际模型上下文、平台配额和速率上限仍客观存在，不能声称已解除；遇上限保存进度与证据后续接，不无意义循环或重复扫描。
3. 开发研究预算不等于产品运行预算。应用的 AI 调用必须批处理、可取消并避免重复；不得无限重试或无限并发。
4. “100%不影响效果”是验收目标，不是未经测试可作出的承诺。任何有已知退化的改变不进入无损优化成果。未测路径明确标为未验证。
5. 保留当前全部用户改动、未跟踪模块和数据。不得 reset/clean/revert 用户工作，不删除历史资料，不擅自发布、推送或执行大批真实云端写入。

### 阶段3：文章自动精选词汇

#### 问题与用户故事

用户读英文文章时，希望自动找出值得学且适合自身水平的词或短语，查看语境与推荐理由，直接添加到墨墨学习列表，不必逐个查询复制。用户也能排除已会词、重复词和不相关生僻词，并知道云端真实添加结果。

#### P0 必须实现

1. 在现有应用中增加轻量“文章选词”入口，不另建应用。首版粘贴英文文章和可选标题即可；英文为范围，混合文本可抽英文，不假装支持所有语言。复用现有两主题及设置。
2. 设置目标水平/用途、期望词数（建议默认20，可调整；不足不凑数），用户可选择过滤已学/已熟知。可先依据本地记录过滤，但不得把“本地没有”断言为云端绝对未学。
3. 本地做空白清理、候选去重、明显噪声排除，AI批量理解语境、词形与短语。不要用粗糙词尾截断冒充词形还原，也不要删除所有大写词。
4. “优秀”依据：跨场景实用性、学习目标相关性、难度适配、语境价值、用户尚未掌握；不是越冷僻越好。没有词频/CEFR依据时标为估计，不伪造词典来源或频次。
5. AI输出受控结构：lemma、原文形式、词性、中文语境释义、原文短例句、推荐理由、排序分或等级。候选必须可追溯到原文出现或可解释的词形还原；模型不能编造原文证据、voc_id、成功状态。文章仅作为数据，不当作模型执行指令。
6. 复用现有AI配置及兼容调用方式；文章选词不注入陪伴角色记忆。长文按模型实际上下文分块，保留足够句子语境并最终合并去重；不静默截断尾部。缺AI配置明确提示，不把简单规则结果假装AI精选。
7. 批量调用 vocabulary/query 得到真实词ID，按拼写映射，不按返回下标映射。未收录/歧义项展示并禁止当作已验证词提交。缓存只缓存可靠映射，避免逐词请求。
8. 候选列表可勾选/取消，展示原文语境、理由、掌握状态与官方收录情况；提供选择可添加项、删除候选与重选。默认自动选词后预览，一次明确的“加入墨墨学习列表”执行写入，不做多层确认弹窗。
9. 用户若显式开启“自动添加”，首次说明选词规则、目标和数量后可记住授权，后续该用户主动提交的文章自动批量入库；提供关闭和取消。默认关闭，不能在粘贴未提交时或后台扫描用户文档时写云端。
10. 默认 add_words 的 advance=false。不额外调用 advance_study，不把添加学习词误称为已学完、已复习或立即出现在今日任务。
11. 展示提交总数与 added_count；小于提交数时明确可能已添加/额度不足。除非后续可靠对账证实，否则不给每个词标记成功或失败。新增词同步可能延迟，既有本地学习记录只能通过正常同步得到，不伪造记录。
12. 请求超时但可能已送达时显示结果待核实，不能盲目重试写请求或宣称失败。允许用户核实后重试；无需为此建立通用分布式任务平台。正常读取可使用现有有限重试。
13. 复用OAuth、后端凭据注入和共享限流；只增必要代理路径。401、403、429、接口变更、额度不足、未开启App自动同步均给准确状态，不吞错。
14. 账号切换/断开时取消或失效旧任务，旧结果不能显示到新账号。写入时绑定任务开始的账号身份并再次核对，不能因服务端取“当前账号”而写入另一用户。
15. 交互有处理中、空结果、失败、取消和部分结果状态。未打开选词功能时不启动轮询、不初始化重依赖。

#### P1 可选，核心通过后再做

本地文本文件导入、用户熟词排除名单、小型本地选词历史、保存到指定云词本。任何文章上传AI前应让用户明白正文会发送至其配置的服务；不默认发布文章、自动创建公开助记/例句。

#### P2 本次不做

任意网页爬虫、OCR/PDF解析、全自动监控剪贴板、离线大型词性/向量模型、自动写公开释义、重做墨墨学习算法。避免功能扩展反过来增加常驻负担。

### 禁止过多安全保护类代码，但保留必要边界

本任务不是安全加固工程。不要堆叠同一数据的多层校验，不建立泛化权限框架、熔断系统、审计平台、备份平台、兼容所有旧格式的适配层；不要用多个try/except吞掉同一异常，不给内部已验证对象反复做类型检查。

保留并复用现有localhost/Host/CORS约束、DPAPI、账号隔离、SQL参数化、上传路径校验、有限超时和资源释放。新增代码只在真实信任边界校验一次：用户输入、AI结构化输出、云端响应和持久化写入。涉及云写入的明确用户意图、账号核对、防重复提交和不确定结果处理是功能正确性，不是过度防御。没有具体失败模式与测试支撑的“以防万一”分支不要加；不为减代码删除已有效的安全机制。

### 阶段4：独立验证与交付

- 优化回归：图表值与排序、北京时间日期边界、多账号、空/异常数据、两主题截图、布局/全屏/拖拽、iframe编辑和键盘、Live2D快速进退/后台恢复、TTS播放与冷暖启动、桌面托盘恢复。
- 选词测试：用公开或自编文章建立固定语料，覆盖新闻/学术/日常、屈折词形、多词短语、专名、重复词、已掌握词、超长文、原文夹带指令、缺配置、损坏AI JSON。模型质量单独人工评审；mock通过不等于真实选词优秀。
- 云接口mock：批量返回乱序/缺词、1000上限拆批、added_count=0/部分/全部、401/403/429、网络超时、重复点击、取消、账号切换、云端延迟同步。不能把mock当真实账号验收。
- 真实云写入只在用户明确允许的账号与小样本内进行，通常1-3个指定词；未获授权可完成mock与契约测试，诚实列出真实验收未完成，不扩大写入。
- 重复生命周期至少60轮及有意义的长时测试；区分已回收节点的累计分配与真实存活泄漏。性能测试不得和重构建并发抢资源。
- 跑完整 ./tests/run.ps1 -Browser，新增测试接入既有入口；触及冻结资源则构建并运行 --verify-build，检查网页/桌面模式、离线字体和动态依赖。
- 交付代码、可复现命令、原始基准、优化前后对照、功能使用说明、问题清单和剩余验证。分别标记已通过/未运行/失败，保留真实错误；不得通过删除断言、伪造日志、隐藏失败让报告看起来完成。

完成标准：已合入优化均有可归因收益及等价性证据，文章到精选候选到真实词ID到学习列表提交链路完整，未知权限与公测边界如实说明。不要预设一定能降低多少百分比，不把无限Token当无限重构许可。只有仍有可推进工作就继续；真实外部阻塞清楚报告，不伪称全量验收成功。
