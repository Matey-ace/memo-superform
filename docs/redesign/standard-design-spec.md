# 普通版视觉与交互规范（standard only）

适用范围：`html[data-ui-style="standard"]`。Anon 的笔记本主题不受本规范影响，
也不加载本规范对应的任何样式或脚本。

## 1. 定位

一套安静的个人自习桌面。使用者每天打开它，最先要知道的是"今天学什么、完成多少、
从哪里继续"。统计、账号、维护属于第二层，需要时能找到，不需要时不占注意力。

明确退出的方向（避免回到上一版的问题）：

- 不做纸张底色 + 黑描边 + 硬投影 + 全直角；
- 不把每个区块都框起来；
- 不用大面积渐变、玻璃拟态、数字墙；
- 不靠装饰字体承担信息层级。

## 2. 视觉基调

| 维度 | 取值 |
| --- | --- |
| 画布 | 近白 `#f7f8fa`（暗色 `#14161a`），不再用米黄纸张色 |
| 表面 | 白 `#ffffff`（暗色 `#1c1f25`），仅一层 |
| 分隔 | 极淡 1px `#e8eaee`（暗色 `#272b33`），只在真正需要分组处出现 |
| 圆角 | 12px 面板 / 10px 控件 / 999px 胶囊标签 |
| 阴影 | 只有一层柔和投影，用于浮层与卡片；hover 不叠加第二层 |
| 主色 | 靛蓝 `#4b6bfb`，仅用于主操作、进度、选中态 |
| 强调 | 完成度用主色的深浅百分比表达，不引入第二种彩色 |
| 语义色 | 成功 `#2f9e6b`、警告 `#c8871a`、危险 `#d05555`，只用于状态文字与小面积背景 |

暗色不是机械取反：画布更暗于表面、边框更弱、主色降饱和（`#7b92ff`）、
阴影改为更淡且更依赖边框。

## 3. 字体

- 正文：系统中文字体栈（`system-ui, "Microsoft YaHei UI", "PingFang SC", "Noto Sans SC"`），
  `-apple-system` 优先，字重 400；不引入 webfont，不修改 `css/fonts.css`。
- 数字与统计数字：同一字体的 `font-variant-numeric: tabular-nums`，
  让数字列对齐，不使用花体或衬线装饰字体。
- 层级只靠字号/字重/颜色/间距四件事：
  - 页面主标题 20px / 600
  - 区块标题 14px / 600，字色降一档
  - 说明文字 12.5px / 400，字色 `--muted`
  - 正文 14px

## 4. 信息优先级

1. **今天**：今天的学习量、完成度、继续学习入口。
2. **主要图表区**：热力图/趋势等磁贴，保持现状功能，只做视觉统一。
3. **次要**：数据同步状态、账号连接状态（胶囊形式，在顶栏可发现）。
4. **低频工具**：收进更靠后的位置或设置页，不占据首屏。

## 5. 组件规范

- **按钮**：三档 —— 主操作（实心主色）、次操作（描边）、文字按钮（仅文字 + hover 底色）。
  统一高度 34px，圆角 10px，hover 只改变背景/边框，不位移、不加粗。
- **输入框**：高度 34px，圆角 10px，边框 1px `--border`，focus 用 2px 主色环。
- **开关**：`input[type=checkbox]` 保持原生，但 label 整行可点。
- **状态提示**：`.status-text` 分 `hint / success / error`，颜色语义化，不加图标字体。
- **进度条**：显示真实完成百分比，0% 时不画填充。
- **浮层**：遮罩 `rgba(16,18,22,.28)`，面板 12px 圆角 + 一层阴影；进入用 160ms
  `ease-out` 的透明度与 4px 位移；`prefers-reduced-motion` 下全部取消。

## 6. 设置页结构：分类目录 → 分类详情

打开设置先给出**分类目录**；窄窗口是独立目录页（带返回），宽窗口是左侧目录 + 右侧详情。
分类必须是使用者能理解的词，不出现内部模块名。

| 分类 id | 名称 | 一句话状态摘要 | 收纳的原有设置 |
| --- | --- | --- | --- |
| `account` | 账号与连接 | 账号是否已连接、能否一键授权 | 墨墨账号（连接/重新授权/断开/手动 Token/删除本机数据）、Codex 账号 |
| `learning` | 学习与进度 | 今天完成情况、数据同步状态 | 数据更新（状态/更新信息/数据范围/完整核验/取消/清除缓存） |
| `companion` | 角色与陪伴 | 陪伴语言、提醒间隔 | 陪伴模式（回复语言、提醒开关、间隔）、Live2D 模型库 |
| `voice` | 语音与音频 | 语音是否就绪 | 语音功能（导入语音包、角色资料包、朗读开关、高级语音设置） |
| `ai` | AI 与记忆 | AI 调用方式与模型 | AI API 配置（调用方式/端点/Key/模型） |
| `appearance` | 外观与窗口 | 当前风格与主题 | 界面风格、运行模式 |
| `maintenance` | 数据与维护 | 版本与更新 | 软件更新 |

约束：

- 每个分类详情有明确标题 + 返回目录入口；宽窗口下左侧目录常驻。
- 保存语义不变：`#saveSettingsBtn` 仍然只在`外观与窗口`等需要显式保存的详情页出现，
  即时生效的选项（陪伴语言、提醒设置、主题）保持即时。
- 切换分类不重建 DOM、不重复绑定事件、不发起请求、不重载大资源：
  所有详情页在页面加载时一次性渲染，切换只改可见性。
- 离开设置前若有未保存内容，切分类/返回/关闭都要提示，不静默丢弃。
- 危险操作（删除本机学习数据、断开连接）单独成块并写明影响。

## 7. 键盘与可达性

- 设置面板已是 `role="dialog" aria-modal="true"` + 焦点陷阱，保留。
- 分类目录是一个 `role="tablist"`，支持 ←/→/Home/End 切换，Enter/Space 进入。
- 所有状态文本使用 `role="status" aria-live="polite"`。
- Escape 关闭最内层，不作为可见按钮的替代。

## 8. 验收方式

由于执行环境无法直接"看"截图，用**程序化视觉 QA**替代目测：几何（位置/尺寸/遮挡/溢出）、
对比度（WCAG 相对亮度计算）、密度（每屏元素数与留白占比）、文字截断（scrollWidth > clientWidth）、
横向溢出、焦点可见性、深浅两版分别测量。任何一项不达标都要改到通过。
