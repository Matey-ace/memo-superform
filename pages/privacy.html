Memo Superform 隐私说明

最后更新：2026-08-31。

本地处理的数据

在你连接账号后，桌面应用会读取你授予权限范围内的学习进度、学习记录和云词本信息，并保存到你设备上的 SQLite 数据库，用于图表、同步状态和复习统计。可选 Live2D、语音包和角色资料也保存在你的设备上。

授权与令牌

一键连接采用 OAuth Authorization Code + PKCE。访问令牌、刷新令牌和 PKCE 校验信息由 Windows DPAPI 加密保存，网页和本项目的 GitHub Pages 不读取令牌明文。手动 Token 是旧用户的可选连接方式，也会迁移到同一份本机加密凭据。

可选 AI 服务

只有在你自行配置第三方 AI 服务后，应用才会把你主动触发的单词列表或陪伴上下文发送给该服务。请同时阅读所选 AI 服务商的隐私说明。

控制与删除

你可在应用设置中断开墨墨账号连接；断开只移除授权。也可使用“删除本机墨墨学习数据”单独清除当前账号的学习记录、同步状态、派生统计和缓存，不会删除墨墨云端数据。

联系

问题或删除请求可通过 项目 Issue 联系维护者。
