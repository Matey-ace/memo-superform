## 接口与生命周期契约

1. Token 只由本机凭据服务托管；浏览器常规内容/AI 请求携带自定义请求头，托管代理校验同源。旧手动 token 仅用于一次性迁移。
2. 账号稳定身份是 profile_id。刷新 token 不改变账号归属，旧账号请求不写新缓存/UI；缓存提交前也检查代次。
3. 墨墨内容接口仅开放 vocabulary/interpretations/notes 指定查询和 CRUD；权限不足保留输入并要求重新授权或复制，云端内容不落 SQLite。
4. 删除只针对当前账号学习表。同步停止确认后事务删除；停止超时保留数据，不报告成功。
5. 合法空列表与协议错误分开；不完整词本允许展示，附 partial/failures/warning，保留重试条件。
6. 词集成员以 notepad_id+word 表示。AI 每次最多提交 200 个不同词，统计数按实际请求和返回计算。
7. 可见学习区域拥有快捷键；编辑/输入法/弹窗隔离快捷键。销毁、退出、换角色后旧异步结果失效。
8. Live2D 主模型/纹理是必要资源；资源复制/下载有累计预算；删除与替换通过受控暂存和恢复记录提交。
9. 更新候选必须仍属于最新 Release 的资产身份。启动成功需要匹配进程初始化确认，失败保留旧版和候选。
10. 发布先完整回归、构建、冻结验收，再推源码和 tag，创建草稿、上传、核验资产，最后公开。已有草稿按明确恢复流程处理，不自动覆盖。
